# Pac-Man

A Python-based Pac-Man game project scaffold.

## Structure

- `src/` contains game logic, entities, UI, and system modules.
- `config/` stores runtime configuration.
- `tests/` contains automated tests.
- `assets/` is reserved for sprites, audio, fonts, and icons.
- `highscores/` stores persisted leaderboard data.

## Quick start

```bash
python3 pac-man.py
```

Or use the Makefile:

```bash
make run
```

## Testing

```bash
pytest
```
