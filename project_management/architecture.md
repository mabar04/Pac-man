# Architecture

The project is organized into gameplay, entity, maze, UI, config, and high-score modules.

- `src/game/` contains the main runtime loop and state management.
- `src/entities/` defines player and ghost logic.
- `src/maze/` loads and interprets maze data.
- `src/ui/` handles rendering and screens.
- `src/config/` manages loading and validation.
- `src/highscore/` stores leaderboards in JSON.
